Worker Runtime

BullMQ worker executes graph runs, resolves artifacts, applies cache keys, stores outputs, and writes telemetry.

Graph System

Storage

S3/MinIO is primary; local fallback stores generated files under .local-storage/ when S3 is unavailable.

Execution Flow

  1. User saves graph JSON from GraphEditor.
  2. Run endpoint creates a Run row and enqueues worker job.
  3. Worker topologically sorts graph tasks and resolves input artifacts.
  4. Each node validates merged default/user parameters and executes or uses cache.
  5. Artifacts are persisted with output keys, MIME metadata, preview data, and history.
  6. Run events, run steps, analytics rows, and billing usage are finalized.
